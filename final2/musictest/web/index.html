前端：這個 HTML／JavaScript　｜　後端：Python FastAPI（同一台 127.0.0.1:8000）

這次在學什麼

瀏覽器（JS fetch） → HTTP → Python FastAPI → 回傳 JSON → 畫面顯示

兩個「語法」不是混在同一個檔：JS 負責畫面與發請求；Python 負責分析。 中間用 HTTP + JSON 說話。

步驟 0：確認後端有在跑

  1. 開啟 Docker Desktop（Engine running）
  2. cd 到 final2\musictest
  3. docker compose up --build（詳見 DOCKER.md）
  4. 瀏覽器開本頁：http://127.0.0.1:8000/

請用上面網址開啟（由 FastAPI 提供頁面）；不要直接雙擊 HTML。
